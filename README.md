# Python Learning — مسیر تمرین‌ها

مخزن آموزشی مستقل برای مرتب‌کردن تمرین‌های پایتون. این نسخه از فایل‌های تمرین پایتونِ بازیابی‌شده از نسخهٔ ثبت‌شدهٔ پروژه تهیه شده است؛ مخزن اصلی و وضعیت Git آن تغییر نکرده‌اند.

## مسیر یادگیری

### 01 مقدماتی
- `01-beginner/01-foundations`: متغیرها، نوع داده، ورودی/خروجی و عملگرها
- `01-beginner/02-control-flow`: شرط و حلقه
- `01-beginner/03-data-structures`: رشته، فهرست، تاپل و مجموعه

### 02 متوسط
- `02-intermediate/01-data-structures`: دیکشنری و تمرین‌های ترکیبی داده
- `02-intermediate/02-functions`: تعریف تابع، ورودی، خروجی و حل مسئله
- `02-intermediate/03-files-modules-errors`: فایل، ماژول و مدیریت خطا

### 03 پیشرفته
- `03-advanced/01-object-oriented`: کلاس و شیءگرایی
- `03-advanced/02-graphics-turtle`: تمرین‌های گرافیکی turtle
- `03-advanced/03-projects`: تمرین‌های ترکیبی و پروژه‌های کوچک

فایل‌های نامشخص در `90-needs-review/` هستند. شمارهٔ هر فایل ترتیب پیشنهادی در همان مبحث است. `INDEX.csv` نام اصلی هر تمرین و محل جدیدش را نگه می‌دارد.

## تاریخ فایل‌ها

نسخهٔ موجود در Git index تاریخ ایجاد/ویرایش فایل‌ها را نگه نمی‌دارد، بنابراین تاریخ واقعی قابل بازیابی نبود و تاریخ حدس‌زده نشده است. اگر نسخهٔ اصلیِ دارای تاریخ فایل‌ها پیدا شود، شماره‌ها را با تاریخ واقعی بازتنظیم می‌کنیم.

## فایل‌های محلی و انتشار

`local-only/` شامل منابع، دفترچه‌ها و مواردی است که پیش از انتشار باید بازبینی شوند؛ این مسیر با `.gitignore` از Git کنار گذاشته شده است. فایل‌های دارای نام شبیه کلید یا دسترسی فقط در `local-only/private-review/` می‌مانند و نباید منتشر شوند.

این مخزن محلی Git جداگانه دارد تا از سایت و مخزن اصلی مستقل بماند. پیش از عمومی‌کردن، کدها باید از نظر رمز، اطلاعات شخصی، مجوز محتوا و صحت آموزشی بازبینی شوند.
